Notation (crow's foot)

Rules the diagram cannot show

One seller per order: every item in an order belongs to orders.seller_id, so the buyer rates one seller (FR6).

Soft delete: a deleted listing gets status REMOVED, so old order_items still point at a real row.

Race safety: paying locks the listing rows (SELECT … FOR UPDATE); version columns are a second safety net.

Review only after COMPLETED and only by the order's buyer (checked in ReviewService).

Services: item_condition is null when type = SERVICE.

Search: 6 indexes on listings serve the FR3 filters; only ACTIVE rows are returned.

Categories: TEXTBOOKS, ELECTRONICS, FURNITURE, CLOTHING, STATIONERY, TUTORING, SERVICES, OTHER. Post categories: ANNOUNCEMENT, EVENT, SERVICE.

Keys: every table has a bigint auto-increment primary key; all foreign keys are NOT NULL.
